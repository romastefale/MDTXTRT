MDTXTRT

Markdown para Telegram

MDTXTRT converte Markdown em rich text do Telegram e exporta mensagens em .md otimizado.

Comandos

  • /start — abre o Mini App e resume o que o bot faz.
  • /helo — este texto: comandos e a diferença entre chat e Mini App.
  • /tgrich — converte Markdown em rich text do Telegram. Responda a um arquivo .md compatível, ou envie o comando seguido do texto. Anexos e encaminhamentos .md disparam isto sozinhos.
  • /mdrich — responda a uma mensagem para exportar .md compatível e otimizado.

Chat vs Mini App

Mini App (botão de /start ou menu): redigir, pré-visualizar, formatar, enviar ao chat e publicar no Telegraph. Use quando for escrever.

Comandos no chat: use quando o texto já está no Telegram — um arquivo, um encaminhamento ou uma mensagem para converter ou exportar.

Nesta interface

  • abrir — carrega .md e mostra o tgrich.
  • mdrich — baixa o documento em Markdown otimizado.
  • chat — envia rich text + .md para o Telegram.
  • telegraph — publica a página (no Mini App).
